# Сайт-резюме Александры Тимохиной

Адаптивный сайт на HTML и CSS: резюме и портфолио.

Публичный адрес: https://aleksandratimokhina.top

## Локальный просмотр

Откройте `index.html` напрямую или запустите простой статический сервер:

```bash
python3 -m http.server 4173
```

После этого сайт будет доступен по адресу `http://localhost:4173`.
